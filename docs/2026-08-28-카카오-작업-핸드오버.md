## 정해진 것과 그 이유

**이동시간은 카카오 길찾기로.** OSRM 은 도로 등급 태그로 미리 구운 자유주행 시간이라
정체를 모르고, 공개 데모 서버라 초당 1회·무보장·예고 없이 차단 가능하다.
카카오가 일률적으로 더 정확한 것은 아니고 다른 경로를 고른다 — 바꾸는 이유는 남의 데모
서버에 기대지 않는 것과 주차장 좌표를 함께 쓰기 위해서다.

**좌표는 두 벌.** `ll` 은 지도에 점을 찍는 자리, `pk` 는 차가 서는 자리.
`ll` 을 덮어쓰면 오름 정상 대신 주차장에 점이 찍힌다.

**REST 키는 코드에 넣지 않는다.** 도메인 제한이 없어 공개 저장소에 박히면 남이 그대로
쓴다. 편집기에서 한 번 받아 브라우저에만 둔다. JavaScript 키는 도메인 제한이 있어
소스에 들어가도 된다.

**가족 공유 목록은 오라클 VM 에.** 깃허브는 쓰기에 토큰이 필요한데 공개 페이지에 토큰을
넣으면 누구나 저장소를 고칠 수 있다(401 로 확인). 오라클에는 이미 Caddy 가 443 에서
HTTPS 를 물고 있어 `/jeju/*` 만 새 포트로 넘기면 된다.

**편집 권한.** 일정은 나만, 맛집·여행지는 가족 각자. 배포판 48곳·51곳과 일정에 쓰이는
장소는 가족이 뺄 수 없다 — 일정이 그 위에 서 있다.

## 확인해 둔 사실 (다시 재지 말 것)

**두 카카오 API 모두 브라우저에서 CORS 가 열려 있다.** `hanbrook3.github.io` 와
`127.0.0.1:8765` 두 원본에서 status 200 을 받았다. **지도 SDK 를 불러올 필요가 없다.**

| API | 주소 | 무료 쿼터 |
|---|---|---|
| 자동차 길찾기 | `apis-navi.kakaomobility.com/v1/directions` | 10,000건/일 |
| 장소 검색 | `dapi.kakao.com/v2/local/search/keyword.json` | 100,000건/일 |
| 지도 Web SDK | — | 300,000건/일 |

- `result_code 0` 이 성공. `102`·`103` 은 좌표가 도로에서 멀다는 뜻이다.
- 등록된 99곳 중 성산일출봉·한라생태숲 둘만 걸렸고 주차장 좌표로 풀렸다.
- 2026-07-21 개편으로 도보·자전거·대중교통 경로가 심사 없이 열렸다.
  자동차 길찾기는 카카오모빌리티 소관이지만 **같은 REST 키로 그냥 된다**(실호출 확인).

주차장 좌표 기준 실측 — 폴백 계수의 근거다.

| 구간 | 직선 | 도로 | 소요 |
|---|---|---|---|
| 성산일출봉 → 천지연폭포 | 42.7km | 49.3km | 71분 |
| 협재 → 함덕 | 43.1km | 52.2km | 68분 |

## 주의할 것

**여러 세션이 같은 파일을 만지고 있다.** `index.html` 을 통째로 다시 쓰지 말 것.
줄 단위로 고치고, 고치기 전에 `git status` 로 남의 작업이 있는지 볼 것.
자세한 것은 `docs/2026-08-28-동시작업-기록.md`.

**윈도우 `curl` 은 명령줄의 한글을 코드페이지로 바꾼다.** 한글이 들어가는 요청은 파일로
보내거나(`--data-binary @파일`) 직접 퍼센트 인코딩할 것. 이것 때문에 장소 검색 조사가
한 번 통째로 헛돌았다.

**`node -e` 는 이 환경에서 막힌다.** 스크립트 파일로 만들어 `node 파일.js` 로 돌릴 것.

**키를 대화·커밋·로그에 남기지 말 것.** 이 세션에서 조사하느라 REST 키를 터미널 명령에
직접 넣었다. 찜찜하면 콘솔 `앱 설정 > 플랫폼 키` 에서 새로 발급하면 된다.
